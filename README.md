This is the THOR version of RTNav used for the Stretch 3 real-world
experiments. It is included as a Git submodule by the companion real-world
repository, which provides the robot setup, calibration, ROS bridge, launch
commands, and experiment procedures. For simulator evaluation, use the
[`main`](https://github.com/generalroboticslab/rt_ovn/tree/main) branch.
